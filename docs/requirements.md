# 駐車場管理ダッシュボード
## 背景
- 当社では月極駐車場の運営事業を行っており、区画ごとに駐車場の利用状況を管理する必要がある。
- 具体的なビジネスルールは `business_rule.md` を参照。

## このシステムで行うこと
- 駐車場の契約状況を管理すること。具体的には以下。
  - それぞれの契約内容とその履歴
  - それぞれの契約に対する請求のステータス
  - 駐車場の各区画の利用状況

## このシステムで行わないこと
このシステムはあくまで管理用のダッシュボードであるため、以下の業務は行わない。

- 契約の締結作業 (契約は紙ベースで行われる)
- 請求書(PDF)の発行
- 請求書決済業務・決済サービスとの連携
- 利用者の駐車場入退場記録の管理
- 駐車場マスタ・区画マスタの管理 (マスタも作る必要があるが、現状では頻繁な増減の予定がないため、このシステムでは参照のみ行う)

## 想定利用者
- 担当者 (当社社員): 自分が契約担当者である区画の利用状況とその履歴・および請求の確認を行う。 
  - 駐車場の利用者向けの機能は提供しない。

## ユースケース
- must: 担当者は、自分が担当である契約の契約内容を登録できる
- must: 担当者は、自分が担当である契約の契約内容を更新できる
- must: 担当者は、契約内容の履歴を確認できる
- must: 担当者は、契約内容の履歴のうち、過去の内容を更新できる
- must: 担当者は、契約に対する請求のステータスを確認できる
- must: 担当者は、駐車場の各区画の利用状況を確認できる
- better: 担当者は、駐車場の各区画の利用状況において、今は空いているが未来の契約で利用されるもの・今利用中だが契約終了日が決まっているものを確認できる
