# 駐車場管理サービスのビジネスルール
システム開発の前提となる、駐車場管理サービスのビジネスルールを以下に示す。

## 用語
- 駐車場: 車両を駐車するための施設。
  - 駐車場は、複数の区画で構成される。
  - 当社が運営する駐車場は今は1つだが、今後事業拡大とともに増加する可能性がある。
- 区画: 駐車場の駐車スペースのこと。
  - 各区画には、駐車場ごとに1番から順に番号が付与される。
  - 各区画に駐車できる車両は1台のみ。その車両は契約で定められており、それ以外の車両は駐車できない。
  - 今は空いている区画であっても、未来の開始日の契約で既に利用されている場合は、別の契約で利用することはできない。
  - 現在は区画の種類は単一のみ。
- 契約: 駐車場の区画を継続的に利用する取り決め。
  - 契約には、契約者が1名・運営企業側の担当者が1名必要である。
  - 1つの契約において、複数の区画が指定されうる。  
- 担当者: 運営企業側で契約を管理する社員。1人の担当者が複数の契約を管理しうる。
- 利用者: 契約を行った顧客。

## 契約の内容
- 利用者は、駐車場の区画を利用するために契約を行う。
  - 契約の締結は紙ベースで行われる。
- 契約の内容は以下。
  - 顧客情報
    - 氏名
    - 住所
    - 電話番号
  - 契約情報
    - 契約開始日
      - 開始日は常に「翌月1日」とする。
    - 駐車場
    - 区画
  - 車両情報
    - ナンバー
  - 担当者
    - 社員コード

## 請求
- 毎月20日時点で、契約の有効期間中の利用者に対して、翌月分の請求書が発行される。
- 現在は1区画あたり月額2万円固定。ただし今後、事業拡大によって料金プランが増える可能性がある。

## 契約情報更新
- 契約の内容に変更があった場合、契約情報を更新する。
  - 「契約の内容」項目で挙げたもののうち、契約開始日以外は変更されうる。
- 契約内容の変更日とその適用日が同じとは限らない。
  - 例えば、契約内容の変更日が2025年1月15日であっても、適用日は2025年2月1日となる場合がある。
- 過去の履歴も修正可能である必要がある。

## 契約更新・解約
- 契約は、前月末までに連絡がない限り自動更新される。
- 利用者から解約の連絡があった場合、その契約は翌月末日で終了する。
